# PHY 607 - Class 2 - Thursday, August 27, 2026

## Class Outline & Plan

0. Check in: is everyone's machine ready (MacOS or Linux)?
1. The terminal and the shell
   * what a shell is; why we work here rather than in a GUI
   * navigating the filesystem: `pwd`, `ls`, `cd`, absolute vs relative paths
   * inspecting and manipulating files: `cat`, `less`, `head`, `tail`, `cp`,
     `mv`, `rm`, `mkdir`
   * finding things: `find`, `grep`, `man`
2. Composing commands
   * standard input, output, and error
   * redirection (`>`, `>>`, `2>`) and pipes (`|`)
   * why this composition is the point of the whole design
3. Shell scripting basics
   * shebang lines, making a file executable (`chmod +x`)
   * variables and quoting
   * arguments and options (`$1`, `$@`)
   * conditionals and loops in bash
   * exit statuses
